popote.kr에서 배운 것

10월 19일 popote.kr을 PC·폰으로 직접 열어 화면 값을 쟀습니다. 1차는 요청서에 적힌 popote.co.kr(기존 몰)을 기준으로 삼아 이 톤과 어긋났습니다. 두 몰이 왜 다른지는 아래에 정리했습니다.

색

바탕 크림 #FBF8F1 본문 흰색 제목 #191919 설명 #666666 머리말 초록 #37874F
  • 초록은 “처음 만나는 뽀뽀뜨” 같은 12px 머리말에만 씁니다. 넓은 면에 칠하지 않습니다.

글자와 사진

  • 글꼴은 전부 Pretendard. 제목 22~27px 굵게, 설명 13px.
  • 상품 사진은 위에서 내려다본 접시, 그레이지 바닥, 옅은 그림자.
  • 로고는 검정 단색, 브랜드 문구는 “현명한 부모들의 선택 · 프리미엄 가정식”.
  • 손으로 그린 선 일러스트(엄마와 아이)를 씁니다.

popote.co.kr과 popote.kr은 왜 다른가

같은 회사(주식회사 뽀뽀뜨)의 쇼핑몰이지만, 서로 다른 두 개의 몰입니다. 2024년에 카페24로 새 몰을 열면서 기존 몰도 닫지 않고 함께 운영하고 있습니다.
